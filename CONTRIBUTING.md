# Contributing to MY_NET Enterprise NOC

Thank you for your interest in contributing to **MY_NET Enterprise NOC**! We welcome bug reports, feature suggestions, and pull requests from the global networking and DevOps community.

## 🤝 Code of Conduct

Please read and follow our [Code of Conduct](CODE_OF_CONDUCT.md) in all community interactions.

## 🐛 Reporting Bugs

Before creating a bug report, please check existing issues. When reporting a bug, please include:
- A clear description of the issue.
- Steps to reproduce.
- Relevant log output (`journalctl -u nms_engine@8000` or `journalctl -u nms_worker@9000`).
- Server OS version and hardware specifications.

## 💡 Feature Requests

We welcome ideas for new features, hardware vendors (MikroTik, Cisco, Juniper, Huawei), and integrations! Please submit a feature request issue outlining:
- The problem you are trying to solve.
- Proposed solution or SNMP MIB / OID details.

## 🛠️ Pull Requests

1. Fork the repository.
2. Create your feature branch (`git checkout -b feature/amazing-feature`).
3. Commit your changes with clear commit messages.
4. Ensure all tests pass.
5. Open a Pull Request against `main`.
